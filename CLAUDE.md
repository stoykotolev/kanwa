# Distributed Systems Learning

This repo works through the [Fly.io Distributed Systems Challenges](https://fly.io/dist-sys/),
implemented in Go and verified with [Maelstrom](https://github.com/jepsen-io/maelstrom).

Learning mode is always on in this repo. The topic is distributed systems:
consistency models, fault tolerance, gossip protocols, consensus, and so on.

Canonical references:

- The [Fly.io challenge descriptions](https://fly.io/dist-sys/)
- _Designing Data-Intensive Applications_ (DDIA)
- The [Maelstrom docs](https://github.com/jepsen-io/maelstrom/tree/main/doc) for checker output and timeline visualisations
